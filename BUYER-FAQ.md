# Buyer FAQ

## Is this the full game or a license sold to many buyers?
The seller is seeking a single outright acquisition of the version-2 project and transferable seller-owned rights. Final rights are defined by contract. No publishing or ongoing revenue-share arrangement is proposed.

## Can I see the source here?
No. The development repository remains private. Qualified source review can be arranged separately; this public repository contains only sales materials and preview images.

## What will I need to build it?
JDK 17, Android SDK/build-tools 34, the included Gradle wrapper (8.7), Python 3.11 and the pinned NumPy/Pillow content-generation dependencies. On first setup the deterministic generator recreates 12 WAV tracks. All 12 were verified against the original files. Local SDK, signing and store configuration must be set up for the buyer's environment.

## Are all assets exclusive?
No. The world-art/music pack has an existing CC0 declaration. Vazirmatn is covered by SIL OFL; dependencies retain their own licenses. These rights cannot be made exclusive by selling the project. The contract must identify the seller-owned rights actually being transferred and the existing license exclusions.

## Do I receive signing keys or store accounts automatically?
No credentials are in this public showcase or the private source repository. Any legally permitted app/signing handover is separately agreed after ownership and platform requirements are checked. A personal developer account is not automatically included.

## Is revenue guaranteed? Is the store listing active?
No revenue or user metrics have been verified for this offer. The earlier Myket listing was deactivated over naming/metadata. This is a sale of project assets; store reinstatement or approval on a different store is not promised. Google Play integration would require additional work.

## Can I download a demo?
There is no public APK or video link on this showcase yet. The existing build-206 APK is available locally with the seller; evaluation delivery can be arranged before a purchase. Source completeness should be checked through a build and hands-on review.

## What has been tested?
128 unit tests and debug lint passed during repository preparation. Soundtrack regeneration matched all 12 original hashes. Two-physical-phone multiplayer and end-to-end store payments remain unverified. Unit tests do not replace device testing.

## What does it cost?
Offers are invited. No fixed asking price or minimum price is committed on this page. The settlement method, eligibility and any fees must be confirmed before agreeing a transaction. No supported-country or payment-provider approval is implied by a GitHub listing.
